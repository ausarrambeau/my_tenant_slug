## Control-Plane Data Wiring (Server-Side Proxy)
This scaffold includes `/api/control-plane/crm/board`, a server route that proxies CRM board data from the centralized control plane.

Required server-only env vars (do not expose as `NEXT_PUBLIC_`):
- `CONTROL_PLANE_BASE_URL` (example: `https://app.getbusy.ai`)
- `CONTROL_PLANE_PROXY_SIGNING_SECRET` (HMAC secret used to mint short-lived proxy JWTs)
- `CONTROL_PLANE_TENANT_SLUG` (tenant slug embedded in each JWT)
- `CONTROL_PLANE_CLIENT_ID` (optional)
- `CONTROL_PLANE_PROXY_TOKEN_TTL_SECONDS` (optional, defaults to `60`)
